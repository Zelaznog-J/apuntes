## Cómo leer los capítulos

Cada capítulo sigue la misma estructura: objetivos, conceptos, ejemplo, ejercicios y referencias. Los capítulos en notebook tienen un botón para descargar el `.ipynb`.

!!! tip "Prerrequisitos"
    Python básico (variables, funciones, listas) y nociones de estadística.
